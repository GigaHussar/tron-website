Installing LineageOS on an Old Motorola G7 Power

August 2026

#hardware

Today I finished installing LineageOS on my old phone. The idea to try a non-Android OS came to me on two separate occasions, and this time it finally stuck.

The first time was when I thought about turning an old smartphone into a little always-on server. That idea immediately ran into a problem in my head: phone batteries are wired differently from laptop batteries, and if I wanted to run one 24/7, I'd want to rip the battery out and replace it with a capacitor so it wouldn't eventually swell up or worse. That felt like a lot of extra work for something that wasn't very important at the time, so I let it go.

Later I read about GrapheneOS and thought I might eventually put it on a Google phone. But before doing that on hardware I actually cared about, I wanted to get familiar with the whole process of flashing a custom OS onto a phone — how difficult it really is, what it looks like step by step. My old Motorola G7 Power turned out to be supported by LineageOS, so it became the practice run before the "big day" with a newer phone.

First surprise: after a factory reset, the phone asked for the old unlock code before letting me into settings. Not a huge deal, but a little unsettling since this phone had circulated through my family and I had no idea who used it last or what code they'd set. After some digging through memory I got it, got back into settings, and enabled ADB debugging.

From there I installed platform tools on my PC and connected the phone, then followed the instructions on the LineageOS site. I was extra cautious the whole way through — I'd read that it's possible to brick a device if you mess up a step, so I read everything twice before touching anything. I also had to install a Motorola driver on the PC and create a Motorola account just to unlock the bootloader; everything else came straight from the LineageOS site.

In the end I got a basic install working, without Google apps. Might go back and add something later, but for now I'm just glad to have gone through the process once on a phone I don't mind experimenting with.
